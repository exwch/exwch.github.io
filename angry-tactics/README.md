# 怒鸟战术 · Angry Tactics

卡牌策略 + 愤怒的小鸟弹射物理的网页 Demo。纯前端、零依赖、零构建。

## 运行

双击 `index.html` 即可（Chrome / Edge / Firefox / Safari 都行）。
不需要装 Node、不需要起服务器、不需要联网。

## 玩法

游戏是「卡牌回合」和「物理弹射」两层循环：

1. **出牌** —— 每回合有能量。鸟牌把小鸟送上弹射架，策略牌立刻生效。
2. **发射** —— 按住弹射架上的小鸟向后拖拽，虚线是弹道预测，松手发射。
3. **技能** —— 小鸟飞行时点击屏幕任意位置触发专属技能。
4. **结算** —— 场上物体全部静止后回到出牌阶段。
5. **结束回合** —— +2 能量、抽 2 张牌，但总回合数有限。

消灭全部猪即通关；回合耗尽还有猪没死就失败。

### 伤害规则

撞击伤害 ≈ `(撞击速度 − 门槛) × 等效质量 × 系数`

-   撞击越快、质量越大，伤害越高；
-   低于门槛的轻微碰撞不掉血（猪的门槛更高，必须"够分量"才算数）；
-   木板 100 血 / 冰块 52 血 / 石头 560 血；猪 120 血。

所以**打断支柱让建筑塌下来砸猪**，通常比硬砸更划算。

## 项目结构

```
outputs/
├── index.html          入口
├── css/style.css       界面样式
└── js/
    ├── physics.js      自研 2D 刚体物理引擎
    ├── data.js         全部数值配置：材料 / 小鸟 / 卡牌 / 关卡
    └── game.js         游戏逻辑、渲染、输入、UI
```

三个脚本都是普通 `<script>`（不是 ES module），所以 `file://` 直接打开也能跑。

## 想改点什么

几乎全部数值都集中在 `js/data.js`：

-   `CONFIG` —— 发射力度、伤害系数、血量门槛、起始能量
-   `MAT` —— 木/石/冰的密度、血量、摩擦
-   `BIRDS` —— 每种鸟的半径、密度、弹性和技能名
-   `LIB` —— 卡牌库（名称、费用、描述、图标）
-   `DECK` —— 牌组构成（直接改这个字符串数组）
-   `LEVELS` —— 关卡布局：`{x, y, w, h, m}` 摆方块，`pigs` 摆猪

坐标约定：地面在 `y = 640`，`y` 向下为正。

## 物理引擎

`js/physics.js` 是一个自包含的冲量法刚体引擎：

-   圆形与凸多边形，SAT 碰撞检测 + 参考面裁剪生成接触流形
-   顺序冲量求解器（16 次迭代）+ 摩擦锥 + 位置修正
-   低速接触不弹跳，避免堆叠抖动
-   休眠机制（失去支撑会自动唤醒），避免"缓慢蠕滑"
-   滚动阻力，避免圆形在地面上永远滚下去

```bash
node ../work/test-levels.js    # 关卡结构稳定性：静置 10 秒不塌陷
node ../work/test-play.js      # 数值平衡：几发能通关、费用与威力是否匹配
node ../work/test-dom.js       # 端到端：用 DOM 桩把整个游戏跑一遍
```
