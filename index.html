Web Game Collection

网页游戏合集

三个纯前端小游戏，都是用 HTML + Canvas 写的，不需要安装任何东西：打开页面就能玩。 点开任意一张卡片即进入对应游戏，游戏内右上角的 🏠 按钮可以随时回到这里。

双人冒险 SUPER DUO BROS

同屏双人横版闯关。按住冲刺键加速跑，空中长按可以飞起来（最多 5 秒），跳跃轻点是 小跳、长按是大跳，两个人各有一个专属技能。两人都碰到旗杆才算过关。

  • 双人同屏
  • 冲刺加速跑
  • 飞行 5 秒
  • 大跳 / 小跳
  • 火焰弹 · 旋风冲刺
  • 2 张关卡
玩家1：A D 移动 · W 跳 · 左Shift 冲刺 · S 飞行 · J 火焰弹
玩家2：← → 移动 · ↑ 跳 · 右Shift 冲刺 · ↓ 飞行 · / 旋风冲刺

货车贪吃蛇 TRUCK SNAKE

你是一辆不能掉头的长头卡车：车头撞、车厢蹭，摩托车碰着你的车队就报废。 每撞毁一辆就多挂一节车厢，连击越高氮气充得越快——车越长转弯半径越大，胆大也要心细。

  • 货车拖挂
  • 氮气冲刺
  • 连击倍率
  • 越开越长
  • 手机方向键
↑ ↓ ← → 转向 · 空格 / Shift 氮气冲刺 · P 暂停 · R 重开 · M 无敌模式

怒鸟战术 ANGRY TACTICS

卡牌策略 + 愤怒的小鸟弹射物理。每回合用能量出牌，把小动物架上弹弓，拖拽瞄准、 松手发射，飞行中再点一下触发专属技能。打断支柱让建筑塌下来砸猪，往往比硬砸更划算。

  • 弹射物理
  • 卡牌回合
  • 六种小鸟技能
  • 三星评价
  • 3 张关卡
鼠标拖拽 瞄准并发射 · 点击画面 触发小鸟技能 · 结束回合 抽牌 +2 能量
